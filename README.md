Project Overview
This project features a smart bracelet prototype aimed at bridging the communication gap for the deaf and mute community. The wearable device is designed to translate hand gestures and sign language into understandable text or audio, facilitating seamless interaction.

Key Features

Translates sign language gestures to assist the deaf and mute community.

Integrates hardware components with software processing.

Developed as a collaborative university project focusing on real-world problem-solving.

Tools & Technologies

Hardware Prototyping (Sensors & Microcontrollers)

Programming Languages (C++ / C)

Software Engineering & System Design
